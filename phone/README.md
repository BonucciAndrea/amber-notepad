# Amber for iPhone (and any phone)

An installable web app: the real Amber interpreter (`amber.wasm`, the engine at 2.9.1) running on the phone,
offline, with its own keyboard.

- **f(x)**, the first keyboard page, has every primitive and adverb: `+ - * % ! & | < > = ~ , ^ # _ $ ? @ . :`,
  `' / \ ': /: \:`, `` ` `` `"` `;`, the brackets (typed as pairs) and `x y z`. Tap a key to type it: the bar
  above the keys says what it does, dyadic and monadic. Hold a key for its card: the examples there were all
  computed by this engine (`tools/genkeys.js`), and tapping one puts it in the editor.
- **q** has the words (`select from where by`, `sum avg`, `aj lj`...), **abc** the letters and digits.
- **The edit bar** above the keys: undo and redo, line up and down, select all or the line, copy, cut, paste
  (the system clipboard, so it works with every other app), run just this line, and the history.
- **Run** evaluates the editor (several lines are fine) and logs the result; tables render as grids.
  In the log, tap an input to edit it again, tap an output to copy it, hold either for copy, run again, remove.
- **Files.** The chip in the header opens them: named scripts kept on the phone, saved as you type. With a file
  open, Run keeps its text; `\l name.k` in any input runs a saved file, so scripts can load each other. Files
  import from and share to the iPhone's Files app (AirDrop, Messages...), and Amber's bundled example scripts
  open as files. With no file open the editor is a scratch line: Run logs it and clears it, like a REPL.
- The menu: snippets, copy the whole log, the system keyboard for long names, A− / A+ text size, clear, reset.
- Nothing leaves the phone. Definitions (`name: ...`) made on the scratch line are replayed at the next start.

## Install it on an iPhone

Service workers and "Add to Home Screen" need HTTPS, so the folder has to be served from somewhere, e.g.
GitHub Pages for this repository (Settings → Pages → the branch, root folder), which gives
`https://<user>.github.io/amber-notepad/phone/`. Open that in **Safari**, tap Share → **Add to Home Screen**.
It then starts full screen from its icon and works with no connection.

On a computer, `python -m http.server` in this folder and `http://localhost:8000/` works too
(`tools/frame.html` shows it at two iPhone sizes).

## Files

| file | what it is |
| --- | --- |
| `index.html`, `app.css`, `app.js` | the app: log, editor, hint bar, keyboard, menu |
| `rt.js` | the engine's runtime: boots `amber.wasm`, `eval`, ANSI to HTML |
| `keys.js` | keyboard data, generated by `tools/genkeys.js` from the engine's own answers |
| `amber.wasm` | the engine, built by `../build-wasm.sh` from Amber 2.9.1 |
| `sw.js`, `manifest.webmanifest`, `icons/` | offline support and the home-screen app |
| `tools/genicons.py` | draws the icons from the logo's polygons |

After rebuilding the engine: copy `../amber.wasm` here and run `node tools/genkeys.js`.
